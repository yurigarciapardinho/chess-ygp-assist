# Sobre o uso

Este é um projeto independente para análise de xadrez no FlyOrDie, sem parceria ou endosso da plataforma. Observe as regras do serviço ao usar assistência durante uma partida.

A análise com Stockfish roda localmente. O acesso ao jogo continua usando os servidores do FlyOrDie. O perfil do Camoufox mantém os dados de login entre sessões.

Consulte [segurança e privacidade](docs/SECURITY.md) e [origem e licenças](THIRD_PARTY_NOTICES.md).
